# 🚀 Welcome to Let's Build Something Amazing!

Welcome to the official onboarding repository! We are thrilled that you are interested in contributing to the project.

Because we want to keep our codebase secure and organized, our GitHub Organization is by invitation only. Follow the steps below to get your official invite and start collaborating.

## 🛠️ How to Join the GitHub Organization

__Step 1: Get your GitHub Username ready__
If you don't have a GitHub account yet, [create one for free here](https://github.com/signup). If you already have one, make sure you know your exact username.

__Step 2: Head over to our Discord Server__
All of our community coordination happens in Discord. If you aren't there yet, join us using the link provided on our [main website](https://letsbuildsomethingamazing.com/).

__Step 3: Post in the `#onboarding` forum__
Once you are in the Discord server, navigate to the `#onboarding` forum channel. Look for the pinned welcome post titled __"🎟️  Get Your GitHub Invite Here!"__ and reply to that specific thread with your GitHub username or a link to your profile.

__Step 4: Watch your email!__
A project maintainer will manually send you an invite to the organization. __This invite will expire in 7 days__, so be sure to check your email (or your GitHub notifications page) and click "Accept".

## 🧭 What's Next?

Once you have accepted the invite:

1. You will have "Read" access to our repositories, allowing you to clone the code, fork the projects, and submit Pull Requests.

2. Head over to the `#beginners-corner` in Discord to introduce yourself to the rest of the team!

3. __Check the documentation:__ As the codebases are built, check out the README.md files in our specific repositories (like the frontend or backend repos) for instructions on how to run the project in a workspace. If you don't find what you're looking for in the README, check that repository's Wiki (located along the top navigation bar next to "Code" and "Issues").

Let's build something amazing!
